- `/v1/catalog` 与 `/v1/papers/:id` 从数据库读取；收藏、举报、关联讨论均查数据库。`node server/content.mjs import paper.json` 可运行中导入/修改，无需重启。

## 4 · arXiv 采集（2026-10-22）

- 配置来源分类、方向、分页大小、单次页数、执行周期；CLI 支持 `--source`、`--ids`、`--from`、`--until`、`--resume`。按更新日期固定时间窗分页，游标与完成水位入库，增量窗口重叠一天防边界遗漏；历史补采不推进增量水位。
- 采用 Python 标准库解析 Atom（拒绝 DTD/实体），限制响应大小与超时，最多三次请求重试。跨进程 SQLite 来源锁确保一次一个请求，间隔至少 3.1 秒。原 ID 不带版本后缀，版本快照留存，旧版本不覆盖新版本。
- 真实验证：arXiv API 获取 1706.03762，第二次执行 changed=0；cs.AI 2025-01-01 至 2025-01-02 分类窗口分批续采 42/42；手动成功后执行一次 scheduler，真实采集下一窗口的首批内容。Mac App 实际搜索并打开新论文摘要成功。
- 隔离测试通过：分页、错误游标保留、失败后续采、版本更新/旧版回放/去重、收藏与讨论关联保留；既有迁移及内容测试通过。
- 定时器由显式启动 `npm run local:scheduler` 控制，默认不装系统自启动。下一阶段将其调整为只投递任务，独立 worker 执行采集。
- 官方依据：https://info.arxiv.org/help/api/user-manual.html 、https://info.arxiv.org/help/api/tou.html 。本阶段只采集元数据，不下载或分发论文 PDF。

## 5 · 独立可靠任务（2026-10-22）

- `local:jobs collect` 投递，`local:worker` 执行；scheduler 改为只投递，不进行网络工作。采集每页持久化后重新排队，避免大窗口独占 worker；页切换不耗用失败重试预算。
- 任务包含状态、进度、结果、错误、有限尝试次数、可执行时间、租约 owner 与心跳；等价活动任务去重，所有状态变更校验 owner。租约过期恢复，超时取消、退避重试、手动重试及事件历史可查询。
- 真实验证：worker 执行 arXiv 1706.03762 任务成功（已有论文未重复入库）。
- 隔离测试通过：真实子进程领取后 SIGKILL，租约到期由新 worker 恢复成功；并发领取防护、去重、达到重试上限、修复后手动重试、超时失败；全部内容/采集/API 回归通过。
- 仅注册实际实现的采集 handler；原文处理和模型生成会在阶段 7 加入，不把未实现任务标成成功。

## 6 · 本地管理工作台（2026-10-22）

- `/admin/` 使用独立管理员账号、8 小时 HttpOnly/SameSite Cookie 和写请求 CSRF 校验；后端校验权限。随机管理员密码以 0600 写入私有数据目录，已有账号不自动重置。
- 页面支持论文搜索/编辑/新增/下架/精选，解读小节与出处编辑、草稿保存、预览、发布和下架；修订号防止旧页面覆盖新草稿，版本选择仅列出实际收录版本。已发布内容修改需复制为新草稿。
- 任务列表/进度/错误/事件及重试；来源选择和手动采集投递；举报处理结果与隐藏内容；账号限制/解除；管理员操作审计。公开接口不会返回未发布草稿和被隐藏的社区内容。
- 全套隔离测试通过：普通账号无管理权限、CSRF 与跨站拒绝、草稿私有、修改/发布/下架、新草稿不覆盖公开版本、举报处理、账号限制、任务去重、管理会话与审计持久化。迁移、采集与任务恢复测试，以及已有 API/Swift 核心/原生 Store/完整 Mac 构建均通过。
- 实际验收：本地 arXiv 论文 1706.03762v7 在浏览器完成草稿创建、修改、预览、发布；确认发布前公开接口 poster=null，发布后 Mac App 显示人工摘要速读与出处。模型未调用，明确不是 AI 生成结果。
