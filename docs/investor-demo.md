# PaperFeed 投资人演示路线 · 约 7 分钟

演示前打开首页，确保个人空间显示“已保存到数据库”。如果需要从头展示，在个人空间重置演示；这会替换当前演示身份的记录，先导出需要保留的内容。

## 0:00–0:45 · 从兴趣出发

首页选择 Agent Memory 和 Agent Systems。

讲述：“我们把前沿研究做成容易进入的内容。用户不必先知道应该搜什么，平台从研究兴趣开始，推荐值得读的论文和官方研究动态。”

展示推荐理由，切换前沿热点与关注动态。指出这是固定的核验内容集与可解释推荐规则，不是实时资讯服务或训练好的推荐模型。

## 0:45–2:00 · 先轻松看懂一个亮点

进入「刷一篇」，播放 Reflexion 讲解。展示分镜随配音变化、字幕、暂停、静音与拖动进度。

讲述：“一条短内容只讲清一个亮点：失败怎样成为下次尝试可以读取的经验。用户可以先理解，再决定是否深读。”

收藏，表达兴趣，然后进入完整解读。说明这版是编辑制作的动态分镜配音，不是作者讲座视频。

## 2:00–3:15 · 从直觉进入证据

打开 Reflexion 的「深入图文」。展示机制图、具体例子和 HumanEval 结果的实验条件；点击原文版本入口。

讲述：“轻松不等于丢掉严谨性。原文报告、编辑类比和使用建议分别标注。尤其不能把带迭代的系统结果误解成任意模型一次生成的水平。”

写一条笔记，例如“比较纯重试和反思，固定总调用预算”，保存并标记已读。

## 3:15–4:45 · 阅读自然转成交流

进入 Agent Memory 社区，加入社区和 Reflexion 共读。

查看共读问题与阅读提纲，发起“怎样过滤错误归因的记忆？”讨论，并追加一条实验设计回复。

讲述：“交流既发生在单篇研究旁，也发生在方向社区里。共读把抽象兴趣变成一个具体共同任务。”

说明示例人物和历史互动有标注；新增内容写入自己的演示空间，没有给真人发消息。

## 4:45–5:30 · 认识研究兴趣附近的人

向下查看「研究兴趣上的附近」，看共同关注的方向、共同收藏或阅读的论文，关注一位示例同行。

讲述：“这里的附近由研究问题定义。匹配理由是可查看的共同内容，而不是一个无法解释的相似度数字。”

## 5:30–6:30 · 知识和关系能够留下

进入个人空间，找到刚才的共读、讨论、回复、关注和笔记。刷新页面，展示记录还在。

打开文库，展示收藏分组与已读状态；导出 Markdown 知识库或 BibTeX，查看文件中的原文链接、解读和个人笔记。

讲述：“内容发现、理解、讨论、同行连接和知识沉淀在同一个流程里完成。用户可以把积累带回现有研究工具。”

## 6:30–7:00 · 回到产品价值

返回首页，展示收藏和兴趣反馈对排序的影响。

讲述：“价值来自连续体验：更低的理解门槛带来更多有效阅读，阅读和交流帮助理解兴趣，再让推荐和同行发现更贴合研究者。”

真实边界：人工整理的固定内容、规则推荐、演示人物；尚无实时采集、自动批量生产讲解、真实社交消息或作者认证。生产规模的内容审核、推荐评估与社区运营仍需后续验证。
