# PaperPop 视觉规范

2026-10-20 · 第二版视觉。实现目标是清晰、轻盈、有编辑感的研究阅读 App。

## 视觉语言

- 画布：浅色 #F5F7FB 附近的冷白，卡片纯白；深色使用深藏蓝，避免纯黑灰色大块堆叠。
- 强调色：钴蓝 RGB(0.24, 0.35, 0.92)。深蓝精选区域搭配低饱和薄荷绿标记。
- 方向配色：智能体记忆蓝、智能体系统绿、测试时学习陶红、世界模型钢蓝、高效模型紫。颜色只作辅助，始终保留文字与图标。
- 字体：中文使用系统无衬线；论文简称使用系统衬线；英文眉题使用小号大写与适度字距。
- 间距：页面边距 22，组件内部 16–22，模块间距 18–23，列表间距 11–12。
- 圆角：搜索框 14、列表卡片 20、精选与 Poster 头部 24。细边框辅助区分白色表面，不使用重投影。

## 页面组织

发现：品牌与通知 → 一句价值说明 → 搜索 → 排序与方向筛选 → 单篇精选 → 紧凑论文列表。精选来自实际内容，不伪造每日更新或热度。

Poster：论文简称与编辑标题 → 可展开的作者和来源 → 核心方法 → 原文证据 → 分节解读 → 关联阅读与交流。编辑类比、原文结论与内容未就绪状态仍明确标注。

社区：方向双列卡片，使用中文方向名、英文研究标签、真实内容数量。方向内提供交流和研究内容两个入口。

资料库：搜索、收藏/稍后读/笔记/已读、分组。个人空间：身份、真实个人统计、研究偏好、外观与数据设置。

导航：统一底部四入口，选中状态通过蓝色、填充图标和底色共同表达；iOS 使用独立导航栈，Mac 预览切换入口时回到该入口首页。

## 图形与工具

- SwiftUI Canvas 绘制研究方向的轨道、节点与连线；SF Symbols 提供语义图标。
- 列表与精选插图是装饰性视觉，不代表论文架构或实验数据，辅助技术中隐藏。
- 方法流程单独用结构化步骤绘制，实际文本来自论文内容，保留放大入口。
- 图标通过 `swift scripts/generate-ios-icon.swift ios/PaperPop/Assets.xcassets/AppIcon.appiconset/AppIcon.png` 重建。
- 通过 CUA 原生界面截图检查真实 SwiftUI 排版，并对首页、Poster、社区、个人空间和筛选导航作交互检查。
